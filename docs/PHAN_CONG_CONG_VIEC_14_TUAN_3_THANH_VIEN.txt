PHAN CONG CONG VIEC DO AN 14 TUAN - 3 THANH VIEN
Ten de tai chinh thuc: Ha tang Giam sat & Bao dong An ninh tich hop Edge AI (YOLOv8) va Mang VPN WireGuard qua Docker
Dinh huong chuyen sau: Phong chay Chua chay thong minh (PCCC - Nhan dien Lua & Khoi) cho Toa nha, Khu cong nghiep, Nha kho / Bai xe thong minh

CONG NGHE THUC TE CUA DU AN
- Backend API: Rust (Axum + SQLx + Tokio + Rumqttc), 9 thu muc tieng Viet, PostgreSQL 16 + Mosquitto MQTT Broker.
- Edge AI (Stream Processor): Rust (Axum + tract-onnx), YOLOv8 Nano/Small (.onnx) nhan dien Lua (fire) va Khoi (smoke) chay local (Jetson Nano / PC GPU GTX 1650+ / CPU).
- Ha tang Mang & Container: Docker Compose, WireGuard VPN Server Container, RTSP Simple Server (MediaMTX), Phan doan VLAN (Camera/IoT - Edge AI/Backend - Quan tri VPN), mo rong Dashboard Grafana.
- Thiet bi IoT PCCC: Camera IP RTSP / Webcam USB, ESP32 (Firmware Rust esp-idf-svc), Cam bien khoi/gas MQ-2, Cam bien lua (Flame/IR), Coi bao dong 12V, Khoa tu Solenoid (mo cua thoat hiem khan cap), Mach Relay kich hoat (bom chua chay / phun suong / coi 12V).
- Web Dashboard: Nginx + HTML5/CSS3/JS (REST API + WebSocket realtime, phan quyen ADMIN/OPERATOR, tu dong do trang thai thuc te).

- Thanh vien 3 - Edge AI (YOLOv8 Lua & Khoi) & IoT ESP32 PCCC: Huan luyen/xuat model YOLOv8 Nano/Small ONNX nhan dien fire & smoke, AI Service Rust (doc RTSP/ffmpeg co timeout, suy luan ONNX + NMS, upload snapshot), Firmware Rust ESP32 doc MQ-2/Flame va dieu khien Relay, Coi 12V, Khoa tu Solenoid co ACK qua MQTT.
